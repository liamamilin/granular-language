6  Attributes

Objects do not appear as empty units. They appear with qualities.

A thing is not only a thing. It is large or small, round or flat, red or gray, warm or cold, smooth or rough, fast or slow. Once language has named an object and placed it within a category, the next step in semantic refinement is to notice its attributes. Attributes make description thicker. They allow language to move beyond bare identification and begin answering a more precise question: not only what is it?, but what is it like?

This is why attributes are one of the first tools of semantic detail.

At the level of ordinary language, attributes help us see that the same category can contain many different forms. Two objects may both be chairs, yet differ in size, shape, color, texture, and weight. Two days may both be cold, yet differ in intensity, wind, brightness, and feel. Two people may both be tired, yet differ in speed, posture, tone, and visible energy. Attributes reveal variety within sameness.

6.1 What is an attribute?

At the level of ordinary language, an attribute is a quality or feature that belongs to an object, condition, or event.

We notice attributes through simple descriptive dimensions such as:

  • size

  • shape

  • color

  • temperature

  • texture

  • speed

Examples include:

  • a large box

  • a round table

  • a red apple

  • warm water

  • rough wood

  • a fast car

An attribute does not usually create a new object.
It refines how the object is seen and described.

6.2 Why attributes matter

Attributes matter because naming alone is too thin for most real description.

We need to know:

  • how one thing differs from another within the same category

  • how qualities can be attached to named objects

  • how language begins to thicken perception

  • how description becomes more precise without yet becoming fully technical

Without attributes, language remains coarse. We may say tree, room, car, voice, or pain, but the world stays too flat. Attributes give texture to attention. They turn a bare category into a more visible form.

6.3 Key distinctions

6.3.1 1. Size

Many objects can be described by how large or small they are.

Attribute Description Examples
large / big greater in overall size a large room, a big dog, a large box
small lesser in overall size a small bag, a small stone, a small plant

Examples:

  • The room is large.

  • The cup is small.

  • She carried a big bag.

  • The tree is too large for the yard.

Size matters because it often affects use, capacity, effort, and relation to other things.

6.3.2 2. Shape

Objects often differ not only in size, but in form.

Attribute Description Examples
round circular or curved in overall form a round plate, a round ball
square / rectangular shaped with straighter edges and angles a square table, a rectangular box
flat / long / narrow other common shape qualities a flat surface, a long stick, a narrow road

Examples:

  • The table is round.

  • The box is rectangular.

  • The road is narrow.

  • The stone is flat and smooth.

Shape matters because it affects recognition, function, and fit.

6.3.3 3. Color

Color is one of the quickest visible attributes.

Attribute Description Examples
basic color a visible color quality red, blue, green, black, white
color contrast difference in color between objects a red apple and a green leaf

Examples:

  • The apple is red.

  • The wall is white.

  • She wore a blue coat.

  • The leaves turned yellow.

Color matters because it often supports recognition, comparison, and emotional or practical judgment.

6.3.4 4. Temperature

Some things are described by how hot or cold they are.

Attribute Description Examples
hot / warm greater heat hot tea, warm water, a warm room
cold / cool lesser heat cold air, cool metal, cold hands

Examples:

  • The tea is hot.

  • The water feels warm.

  • The room is cold.

  • His hands were cold.

Temperature matters because it affects comfort, safety, function, and bodily experience.

6.3.5 5. Texture

Objects differ in surface quality and feel.

Attribute Description Examples
smooth even, soft, or without roughness smooth glass, smooth skin
rough uneven or harsh to the touch rough wood, rough stone
soft / hard yielding or resistant to pressure soft cloth, hard metal

Examples:

  • The table feels smooth.

  • The wall is rough.

  • The blanket is soft.

  • The floor is hard and cold.

Texture matters because it connects visual description with touch and practical use.

6.3.6 6. Speed

Some objects, actions, or changes are described by how fast or slow they move or happen.

Attribute Description Examples
fast high speed a fast car, quick movement, rapid change
slow low speed a slow walk, slow growth, slow response

Examples:

  • The car is fast.

  • He walks slowly.

  • The river moved slowly.

  • The machine works too fast.

Speed matters because it affects timing, risk, efficiency, and experience.

6.4 Core patterns

This chapter rests on a few basic patterns.

6.4.1 Basic semantic patterns

  • Objects have attributes.

  • Attributes refine description.

  • The same category can contain objects with different attributes.

  • Attributes make language more precise.

  • A thing may be described through several attributes at once.

6.4.2 Basic language patterns

  • ___ is big / small.

  • ___ is round / flat / narrow.

  • ___ is red / blue / green.

  • ___ is hot / warm / cold.

  • ___ feels smooth / rough / soft / hard.

  • ___ is fast / slow.

  • The ___ has the attribute of ___.

  • This object is ___ in size / shape / color.

6.5 Attributes and the movement of this volume

Attributes are the first major step from naming toward qualification.

6.5.1 Naming selects

  • A word first picks out an object.

6.5.2 Categories group

  • The object is placed within a class.

6.5.3 Specificity narrows

  • The object may be named more broadly or more narrowly.

6.5.4 Attributes refine

  • The object is now described through qualities.

This is a major semantic shift. Language is no longer only asking what is it called? It is beginning to ask what is it like?

6.6 Examples

Here are some clean examples of attribute language.

6.6.1 Size

  • The box is large.

  • The cup is small.

  • The tree is tall.

  • The bag is too big.

6.6.2 Shape

  • The plate is round.

  • The box is square.

  • The road is narrow.

  • The stone is flat.

6.6.3 Color

  • The apple is red.

  • The wall is white.

  • The car is black.

  • The sky turned gray.

6.6.4 Temperature

  • The soup is hot.

  • The room feels warm.

  • The water is cold.

  • The air is cool this morning.

6.6.5 Texture

  • The cloth is soft.

  • The table is smooth.

  • The wood feels rough.

  • The floor is hard.

6.6.6 Speed

  • The car is fast.

  • The child ran quickly.

  • The old man walks slowly.

  • The process is too slow.

These examples show that attribute language often includes:

  • visible quality

  • tactile quality

  • measurable tendency

  • descriptive refinement

  • contrast within a category

6.7 Why this matters

To understand attributes is to understand how language begins to make the world more visible.

Without attributes, categories remain too flat. We may know what something is called, but not how it differs from other things in the same class. Attributes give shape, scale, color, feel, and motion to language. They make thought more discriminating.

Attributes are also essential because many later structures depend on them:

  • degree will place attributes on scales

  • measurement will make some attributes more exact

  • comparison will sharpen difference through attributes

  • perspective will later affect which attributes are noticed first

  • finer semantic control begins when bare names become qualified descriptions

Granular language therefore requires more than selecting and grouping. It requires seeing the qualities that make one instance different from another.

6.8 Chapter summary

This chapter introduces attributes as the qualities that make description more detailed.

Objects have attributes, and those attributes allow language to move from simple naming toward finer characterization. Common examples include size, shape, color, temperature, texture, and speed.

The central lessons of this chapter are:

  • objects have attributes

  • attributes refine description

  • the same category can contain different qualities

  • size, shape, color, temperature, texture, and speed are basic descriptive dimensions

  • attributes increase semantic resolution

  • description becomes more exact when qualities are named clearly

To recognize attributes is to move from what something is toward what it is like. This is one of the first and most important steps in increasing the resolution of thought.
